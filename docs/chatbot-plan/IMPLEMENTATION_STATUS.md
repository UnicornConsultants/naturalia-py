# 獨立測試版實作紀錄

日期：2026-11-24

用戶確認暫時沒有 SHOPLINE 授權，先完成可獨立測試版本。AI 使用 Staff AI Agent 的 Kimi API 設定；不沿用其 Agent 程式。

## 已實作及離線驗證

- 188 件真實商品、本機向量索引、字詞混合搜尋及商品卡片。
- Kimi API adapter、引用核對及失敗降級；未執行真實付費推理。
- 客服政策原文摘錄與來源連結。
- 訪客 session、SQLite 對話保存、隔離、清除及過期處理。
- 可嵌入聊天按鈕、iframe、示範頁及手機樣式。
- 13 項單元測試通過，涵蓋搜尋、條件篩選、對話隔離及假的 Kimi HTTP 回應。
- 8 項本機語意評測通過：5 項真實商品召回、3 項無關查詢。
- HTTP 驗證：session 建立、政策回答、歷史隔離、清除及靜態頁面正常。
- 前端 JavaScript 語法檢查通過。

## 尚未驗收

瀏覽器控制主機不可用，尚未完成視覺及操作驗收。按來源專案要求，付費模型驗證須使用 Chrome 逐條提問；真實 Kimi 連線與回答尚未驗證。因此這是實作完成、仍有外部驗收待辦的獨立測試版，不能標為正式上線完成。

SHOPLINE OAuth、會員資料、即時商品資料、充值及扣款屬待授權後的下一階段，目前明示未開通。

啟動及設定見 [開發說明](../../chatbot/README.md)。

## B2B 管理後台第一階段

已加入員工登入／角色、公司客戶、充值方案版本、收款證明附件、核款入帳、獨立帳本、CSV、稽核及專門 WhatsApp 連接頁。入口 `/admin`，主資料庫等候用戶建立第一位管理員。新增後 Python 共 30 項、WhatsApp 8 項測試通過。瀏覽器畫面驗收未完成，取貨扣款及退款屬下一階段。詳見 [後台說明](../../chatbot/ADMIN_README.md)。
